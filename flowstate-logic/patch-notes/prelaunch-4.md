# Prelaunch 4 (0.9.4)

The Logic First curriculum now grants XP, crystals, cores, daily-goal
credit, streak progression, and unlocks achievements - the way the
classic 18-module bank always has. Until this release Logic First
only marked progress; none of the reward loop actually fired. That
ends here.

## 🚀 New

- **Logic First lessons + capstones now grant rewards on every
  completion.**
  - **Per lesson:** +15 XP, +20 crystals. Perfect (no misses on the
    interaction or mini-check) adds +5 XP / +10 crystals.
  - **Per capstone:** +40 XP, +75 crystals, +5 cores. Perfect adds
    the same bonus.
  - **Finishing a chapter's last lesson:** +50 crystals, +3 cores
    on top.
  - **Finishing the very last chapter:** +500 crystals, +25 cores.
  - Daily goal, flow streak, and level-ups now all advance from
    Logic First sessions too, not only the legacy question bank.
- **Inline reward celebration** right on the lesson / capstone
  screen - a reward card appears below the mini-check with banners
  for daily-goal hit, level-up, flow-saved, chapter complete, and
  curriculum complete, plus stat rows for what you earned. No
  second screen, no extra tap.
- **Five new Logic First achievements:** Found Your Footing (finish
  Chapter 1), Halfway There (clear 5 of 10 chapters), Logic First
  (clear every chapter), Integration Check (clear your first
  capstone), and Synthesizer (clear every chapter capstone).
- **Existing volume + accuracy achievements** (First Lesson,
  Flawless, Century, Marathon, Hot Streak, Flow State, and more) now
  count Logic First attempts in their totals.

## 🐛 Fixed

- **Chapter 1 / Lesson 1 no longer reads as a trick question.** The
  interaction referenced a tile the learner wasn't actually standing
  on. O.B. now clearly moves to a new room with a new tile first.
- **Achievement unlock toasts now always appear at the top of the
  screen,** regardless of scroll position.
- **Practice tab now surfaces Logic First chapter practice.**
  Previously it only served the legacy 18-module review queue, so
  Logic First learners who hadn't unlocked Advanced Practice saw an
  empty state that promised practice that never showed up. Every
  completed Logic First lesson now appears in a "CHAPTER PRACTICE"
  section, grouped by chapter.
